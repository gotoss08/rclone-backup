Privacy Policy

rclone-backup. Effective 10 October 2026.

What this is

rclone-backup is a private OAuth client for the open-source tool rclone, used only by its owner to back up their own data to their own Google Drive.

Data accessed

The client accesses files in the Google Drive of the account that authorizes it, only to create, list, update and delete backup files.

Data storage and sharing

rclone runs on the owner's own machines. The OAuth token is stored locally in the rclone configuration file. No data from Google Drive is collected, stored on any third-party server, shared with third parties, used for advertising or used to train AI models.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. After that the stored token stops working.

Google API compliance

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Политика конфиденциальности

rclone-backup — личный OAuth-клиент для утилиты rclone, которым пользуется только его владелец для резервного копирования своих данных на собственный Google Диск.

Клиент обращается к файлам Google Диска авторизовавшего его аккаунта только для создания, просмотра, обновления и удаления файлов резервных копий.

rclone работает на машинах владельца, OAuth-токен хранится локально в файле конфигурации rclone. Данные с Google Диска не собираются, не хранятся на сторонних серверах, не передаются третьим лицам, не используются для рекламы и обучения моделей ИИ.

Отозвать доступ можно в любой момент на странице myaccount.google.com/permissions.
